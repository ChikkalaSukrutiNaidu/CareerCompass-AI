# CareerCompass AI 🚀

A Multi-Agent AI Career Decision Support System built using LangGraph.

## Problem Statement

Students often receive multiple placement offers but struggle to determine which offer best aligns with their long-term career goals.

CareerCompass AI uses multiple AI agents that collaborate to analyze job offers based on salary, technology stack, career growth, work-life balance, higher studies, and user preferences to generate personalized recommendations.

## Tech Stack

- Python
- LangGraph
- LangChain
- FastAPI
- Groq LLM
- SQLite
- React (Frontend)
